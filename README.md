# Abhishek Dound — Portfolio

Personal portfolio of Abhishek Dound, AI/LLM & Backend Engineer.

Built with React 18, Vite, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content

All text, links, projects, skills and achievements live in [`src/data.js`](src/data.js).
Put your resume at `public/resume.pdf` to enable the Resume download button.

## Build

```bash
npm run build    # output in dist/
npm run preview  # serve the production build locally
```
